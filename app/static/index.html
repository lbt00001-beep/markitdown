Que hace esta app

Esta app transforma archivos, paginas web o texto pegado en un archivo Markdown. Markdown es texto normal, pero ordenado: los titulos, listas, enlaces y tablas quedan escritos de una forma clara.

Ejemplo: si subes un PDF con apuntes, la app intenta sacar el texto y lo deja preparado para copiarlo, guardarlo o usarlo en otra herramienta.

Uso normal

  1. Entra en Convertir.
  2. Deja marcada la opcion Archivos.
  3. Selecciona uno o varios documentos.
  4. Pulsa Convertir archivos.
  5. Revisa un resultado a la derecha o descargalo.

Si subes varios archivos, aparece un menu para elegir cual quieres leer. Tambien puedes descargar todos los resultados juntos en un ZIP. Para la mayoria de tareas no hace falta tocar Opciones avanzadas.

Tipos de entrada

Archivos
Para subir documentos de tu ordenador, como PDF, Word, Excel, PowerPoint, imagenes o ZIP.
URL
Para pegar una direccion de internet, por ejemplo una pagina web o un video de YouTube.
Texto
Para pegar directamente un texto, una tabla CSV, HTML, JSON, XML o Markdown.
URI
Es una entrada mas tecnica. Usala solo si sabes que tienes una direccion especial como data: o file:.

Resultado e historial

Resultado es la zona donde aparece el texto convertido. Si conviertes muchos archivos a la vez, usa el menu Resultado que quieres revisar para pasar de uno a otro. El boton C significa copiar. El boton D descarga el resultado en formato Markdown. El boton PDF permite descargar el texto convertido a PDF de forma nativa. El boton ZIP descarga todos los resultados completados del lote.

Historial guarda lo que has convertido mientras la app sigue abierta. Si algo falla, ahi veras el mensaje de error.

Opciones avanzadas

Si no sabes si necesitas una opcion avanzada, normalmente no la necesitas. Sirven para casos concretos.

Conversores internos
Dejalo activado. Son las herramientas normales que convierten PDF, Word, HTML, imagenes y otros formatos.
Plugins
Son complementos extra. Solo sirven si alguien ha instalado plugins de MarkItDown en este ordenador.
Pistas de archivo
Ayudan cuando la app no reconoce un archivo. Por ejemplo, puedes indicar .csv si sabes que es una tabla CSV.
Data URIs completas
Una data URI puede contener un archivo entero dentro de un texto muy largo. Normalmente es mejor dejarla acortada.
HTML estricto
Si se activa, un HTML demasiado complejo produce un error. Apagado, la app intenta rescatar al menos su texto.
Exiftool y style map
Son opciones para usuarios avanzados: metadatos de imagenes y reglas especiales para documentos Word.

OpenAI: describir imagenes

OpenAI es un servicio de inteligencia artificial por internet. En esta app solo se usa cuando activas Describir imagenes con LLM. La imagen se envia al servicio y la respuesta se anade al Markdown como una descripcion.

  • Necesitas una clave de la API de OpenAI. Una suscripcion de ChatGPT no incluye automaticamente el uso de la API.
  • La API puede cobrar por uso. Las imagenes grandes suelen consumir mas que las pequenas.
  • El modelo indica que inteligencia artificial analizara la imagen. El prompt explica que quieres que describa.
  • La direccion compatible con OpenAI solo se cambia si utilizas otro proveedor que funciona de la misma manera.

Azure: documentos y multimedia

Azure es la plataforma de servicios por internet de Microsoft. MarkItDown puede usar dos herramientas de Azure.

Document Intelligence
Lee documentos e imagenes dificiles. Reconoce texto escaneado, orden de lectura, tablas y estructura.
Content Understanding
Analiza documentos, imagenes, audio y video. Tambien puede obtener datos concretos, como fechas, importes, nombres o temas.
Endpoint y analyzer
Endpoint es la direccion de tu servicio de Azure. Analyzer es la receta que decide que debe buscar y como ordenar el resultado.

Coste, privacidad y claves

  • Las conversiones normales se hacen en tu ordenador. No necesitan OpenAI ni Azure.
  • Cuando activas OpenAI o escribes un endpoint de Azure, el archivo elegido se envia a ese servicio por internet.
  • OpenAI y Azure pueden cobrar por cada uso. La app no controla sus precios ni tu saldo.
  • La clave funciona como una contrasena. No la envies a otra persona ni la incluyas dentro del programa.
  • Cada usuario debe utilizar su propia cuenta y su propia clave. La app usa la clave durante la conversion y no la guarda.

En resumen: para PDF, Word, Excel, PowerPoint, HTML y otros archivos normales, deja estos servicios apagados.

Seguridad y errores

  • La app bloquea direcciones internas del ordenador para evitar accesos no deseados.
  • file:// permite leer archivos locales por direccion. Activala solo si sabes que ruta estas usando.
  • La version para Windows incluye la herramienta necesaria para leer MP3 y MP4.
  • Si una conversion falla, revisa Historial. El mensaje suele decir que archivo u opcion dio problema.
